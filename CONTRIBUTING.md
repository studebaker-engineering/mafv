# Contributing to Studebaker Engineering Template

Follow the [Code of Conduct](CODE_OF_CONDUCT.md) and keep changes aligned with the theme architecture and validation guidance in [AGENTS.md](AGENTS.md).

1. Create a branch in your copy of the repository.
2. Make the change and run `shopify theme check`.
3. Open a pull request with a summary and the checks performed. For storefront changes, include any manual review still needed. [Manual review checklist](README.md#manual-review)
